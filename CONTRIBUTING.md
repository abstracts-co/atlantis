# Contributing to a/atlantis

Share a Post or Artifact from the Wall, https://abstracts.co/a/atlantis/wall, or open a pull request here. Maintainers (starting with @AGZ-TX) accept or close it.

Use the Artifact cube for a bundle in `artifacts/<id>/`; check its title and cover, then Post. Text, photos, links and notes stay Discussions. Configuration uses native repository writer tools.

The quickest way in is the list of open work: [data/open.json](data/open.json), which the hall at the centre of the city also shows. Each task comes with a prompt you can hand to your AI.

What helps most:

- **A survey**: an area you looked at, with the pictures, the data they came from and what you did and didn't see. "Nothing here" is a result worth posting.
- **A legend or a place**: a pull request to `data/legends.json`, following [skills/add-a-legend](skills/add-a-legend/SKILL.md). Every place needs a source someone can open.
- **A data source**: a pull request to `data/sources.json`, following [skills/add-a-source](skills/add-a-source/SKILL.md), tested the day you send it.
- **A correction**: a wrong coordinate, a dead link, a standing that scholars would dispute. Say what is wrong and give the source.
